# Privacy Policy – Walking Dad GC01 Test

Last updated: October 17, 2026

## 1. Purpose

Walking Dad GC01 Test is a technical beta application developed
solely to test the display of custom activity summary metrics
in Garmin Connect.

## 2. Data Processing

The application creates standard Garmin walking activities
and adds six synthetic test values to the activity's FIT data.

In test case B, it also adds synthetic padding data to test
the FIT developer data storage budget.

These synthetic values do not represent actual walking
distances or durations.

The recorded activity itself may contain information generated
by Garmin's standard activity recording functionality.

## 3. Data Storage and Sharing

The application does not require user registration.

The developer does not operate an independent backend for
this test application and does not automatically receive
activity data.

Activity data may be synchronised with Garmin Connect.
Garmin processes this data according to its own privacy policies.

## 4. Tracking and Advertising

The application does not use advertising, independent
analytics services, or third-party tracking.
